# Notes Along the Way

A personal site for publishing papers, reflections, and learning notes.
Built with Jekyll and hosted free on GitHub Pages.

- **To write and publish:** see [HOW-TO-WRITE.md](HOW-TO-WRITE.md).
- **To change the title, your name, or section text:** edit `_config.yml`.
- **To edit the About page:** edit `about.md`.

## Folder map

| Folder / file     | What it holds                                  |
|-------------------|------------------------------------------------|
| `_posts/`         | Your writing, one file per piece               |
| `assets/papers/`  | PDFs you want readers to download              |
| `assets/images/`  | Images used in posts                           |
| `about.md`        | The About page                                 |
| `_config.yml`     | Site title, author, sections                   |
| `_layouts/`, `_includes/`, `assets/css/` | The design (no need to touch) |
